Buenas prácticas para llegar a la bandeja principal

  1. Envía desde un dominio propio (ej. hola@feriadelauva.co) con SPF, DKIM y DMARC configurados en tu proveedor.
  2. Si el dominio es nuevo, empieza con pocos envíos diarios y sube poco a poco (ajusta DAILY_LIMIT).
  3. Escribe como una persona: asunto claro, sin MAYÚSCULAS ni muchos signos de exclamación.
  4. Envía siempre una prueba a Gmail y Outlook antes de lanzar.
  5. Nunca reactives a quien se dio de baja: el sistema lo bloquea automáticamente.

Conexiones

Conectar Instagram

  1. La cuenta debe ser Profesional (Empresa o Creador).
  2. Crea una app en developers.facebook.com con el producto “Instagram”.
  3. Genera un token con los permisos instagram_basic, instagram_manage_insights y pages_read_engagement.
  4. Copia el token y el ID de la cuenta en IG_ACCESS_TOKEN e IG_USER_ID, y reinicia el servidor.

Solo usamos la API oficial de Instagram: sin extraer datos de la página, sin riesgo de bloqueo para la cuenta.
